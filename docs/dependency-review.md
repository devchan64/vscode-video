# 단계 0 의존성 및 패키지 검증

확인일: 2026-11-16. 이 문서는 개발 환경과 시험용 VSIX의 검사 기록이며 배포 승인이 아니다.

- 런타임 npm 의존성은 없다. `@vscode/test-electron`, `ws`, `@vscode/vsce`는 개발·테스트 전용이며 `npm run package`는 `--no-dependencies`로 패키징한다.
- `npm run package`는 시험용 VSIX를 만들고 압축 내용을 검사한다. 실행에 필요한 `src` 세 파일과 매니페스트가 있고 `node_modules`, 테스트·외부 바이너리가 없음을 확인한다. 라이브러리나 코덱은 동봉하지 않는다.
- 설치된 개발 의존성 메타데이터의 다수는 MIT, ISC, BSD, Apache 등으로 표시된다. `@vscode/vsce-sign`과 플랫폼별 서명 구성 요소에는 별도의 Microsoft 라이선스가 있으며 재배포 제한이 있다. 개발 도구에만 남기고 VSIX에 포함하지 않는다. 메타데이터만으로 모든 전이 의존성의 배포 적합성을 보증하지 않는다.
- `npm audit --omit=dev`는 0건이다. 전체 개발 의존성 감사에서는 `@vscode/vsce`의 `glob`/`minimatch` 경로에 중간 등급 3건이 보고되었다. 이들은 시험용 패키지에 포함되지 않지만 개발 환경의 잔여 이슈이며 업데이트를 추적한다. 현재 설치 환경의 Node 20.18.1에서는 일부 Azure 개발 의존성이 Node 22 이상을 권장해 npm이 엔진 경고를 출력한다. 실제 패키지 생성은 확인했으며 환경 호환성은 추후 정리한다.
- 프로젝트 자체 라이선스와 저장소 주소가 미정이다. `vsce`는 라이선스 파일이 없다고 경고하며, 현재 VSIX는 **개발용 검사 산출물**이다. 권리자가 라이선스와 배포 정보를 결정하고 필요한 고지·서드파티 조건과 실제 설치를 재검증하기 전에는 출시하지 않는다.
- 외부 FFmpeg와 코덱은 단계 1에서 별도 검증한다. 합성 미디어 픽스처는 아직 생성·배포하지 않았으며 출처와 예상 결과는 이를 도입하는 단계에서 기록한다.
