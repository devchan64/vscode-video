# 단계별 구현 계획

상태: 전체 미착수. 각 단계는 앞 단계의 계약을 사용한다. 기능별 테스트와 실제 Extension Development Host E2E는 해당 동작이 구현되는 단계에서 함께 추가한다. 테스트가 없거나 실행하지 못한 항목은 완료로 표시하지 않는다.

## 0. 기반과 범위 확정

- VS Code 확장 골격, 프로젝트 생성·열기 명령, Webview, 빌드 및 테스트 실행 환경을 구성한다. 격리된 Extension Development Host E2E를 구성한다.
- 대상 OS·아키텍처, 프로젝트 형식과 초기 미디어 조합, 성능 측정 환경을 정한다. 프로젝트 라이선스는 권리자가 결정한다.
- 합성 픽스처 생성과 출처·라이선스·기댓값을 기록한다. 체크리스트와 CI에서 실행할 실제 명령을 문서화한다.
- **완료:** 확장 활성화와 빈 편집기 열기가 E2E에서 통과하고, 단위·E2E 실행 및 실패 로그 확인 방법이 재현된다.

## 1. 엔진과 라이선스 검증

- FFmpeg + libvpx + libopus의 재배포 가능한 빌드를 플랫폼별로 시제품 검증한다. 버전·해시·빌드 옵션·라이선스와 특허 허여 조건을 기록한다.
- WebM/VP9/Opus의 probe, 탐색·정확한 프레임 디코딩, 인코딩·재디코딩과 성능을 확인한다. CFR, 비정수 FPS, VFR 및 키프레임 사이 프레임을 검증한다.
- 배포 패키지의 고지, 대응 소스 제공과 교체 의무 등 해당 조건을 확인하고 실행 가능한 전달 방식을 선택한다. 성립하지 않으면 후보를 변경하고 범위를 갱신한다.
- **완료:** 실제 바이너리 기준 기능·라이선스 검증 기록과 통합 테스트가 있고, 미확정 조건은 분명히 기록되어 있다. 구현 후보 선택은 릴리스 법적 승인과 구분한다.

## 2. 프로젝트와 타임라인 모델

- 유리수 시간, 프레임·샘플 변환, 스키마 검증, 클립·트랙 모델과 비파괴 편집 명령을 구현한다.
- 트림, 분할, 이동, 삭제·리플 삭제, 연결 A/V, undo/redo를 구현한다. 저장·열기, 버전 검사, 원본 누락 및 재연결을 구현한다.
- **검증:** 구간 양 끝, 한 프레임, 충돌, 연결 클립, 비정수 FPS, 직렬화와 이력 복원을 단위 테스트한다. 프로젝트 문서 연결이 준비되는 대로 E2E에서 저장·재열기 및 원본 누락 복구를 검증한다. 이 단계에는 파일 수준 통합 테스트를 먼저 수행하고 해당 E2E는 단계 4 완료 전 필수로 통과한다.
- **완료:** 모델 동작이 상세 설계의 불변식에 맞고 원본이 변경되지 않는다.

## 3. 미디어 가져오기와 프레임 탐색

- 프로세스 작업 관리자와 probe, 프레임 추출, 썸네일·파형 캐시를 구현한다. 빠른 탐색 요청 취소와 오래된 응답 폐기를 구현한다.
- 원본 미리보기, 재생 헤드, 프레임 이동, 이미지 저장, 지원 실패 안내를 제공한다.
- **검증:** 실제 엔진으로 PTS와 키프레임 사이의 식별 프레임을 비교한다. E2E에서 파일 가져오기, 프레임 이동·추출과 실패·연속 탐색을 확인한다.
- **완료:** 지원 범위가 문서화되고 추출 프레임이 기대 위치와 일치한다.

## 4. 타임라인 UI와 편집

- 영상 트랙 및 여러 오디오 트랙, 확대·축소, 스크롤, 스냅, 클립 선택·이동·트림·분할·삭제와 리플 삭제를 제공한다.
- 확장 호스트 모델을 상태의 기준으로 사용하고 UI 메시지 및 경계를 검증한다. VS Code 테마, 키보드 조작과 오류 상태를 지원한다.
- **검증:** 모델 단위 테스트와 E2E에서 영상 두 개의 분할·정렬, 연결 A/V, undo/redo 및 저장·재열기를 확인한다.
- **완료:** 편집 결과가 UI와 저장된 모델에서 동일하고 재열기 후 유지된다.

## 5. 오디오와 타임라인 재생

- 오디오 분리·삭제, 다중 트랙, 게인·음소거, 페이드와 파형을 구현한다. 샘플레이트 변환·채널 믹싱을 고정하고 미리보기의 오디오 시계와 영상 동기화를 구현한다.
- **검증:** 알려진 신호로 게인, 합산, 무음, 페이드, 클리핑, 시작 오프셋을 검사한다. E2E에서 원본 오디오 분리와 배경음악 믹싱 및 재생 상태를 확인한다. 장치 기반 청감과 동기화는 환경을 명시해 별도 실측한다.
- **완료:** 편집된 오디오와 영상이 일관된 타임라인 규칙으로 재생된다.

## 6. 렌더링과 내보내기

- 프로젝트 스냅샷에서 WebM/VP9/Opus 출력, 설정, 진행률, 취소 및 임시 파일 정리를 구현한다. 원본·프로젝트 덮어쓰기를 방지한다.
- **검증:** 출력 재디코딩으로 프레임 경계·순서·길이, 음소거와 믹싱 신호, A/V 동기화를 검사한다. 손실 압축 허용 오차와 계산 방법을 테스트에 명시한다. 취소·쓰기 실패도 검사한다.
- **완료:** 전체 사용자 흐름 E2E가 통과하고 출력이 프로젝트와 일치한다.

## 7. 배포 준비와 회귀

- 자동 저장·백업·복구를 구현하고, 성능 및 대용량 처리, 접근성, 플랫폼별 오류를 점검하고 지원 범위와 제한을 문서화한다.
- 실제 VSIX에 포함된 바이너리·라이선스·고지·필요한 소스 제공 경로를 검사하고 깨끗한 환경에서 설치·E2E·출력을 확인한다. 대상 플랫폼별 빌드 옵션과 해시를 기록한다.
- **완료:** 필수 테스트와 E2E 통과 기록, 수동 검증 및 남은 제한, 라이선스 검토와 패키지 검증 결과가 있다. 미확정 배포 권리나 실패한 필수 검증이 있으면 배포 준비 완료로 표시하지 않는다.

## 단계 간 공통 완료 조건

- 동작과 경계의 자동 테스트를 추가하고 관련 단위·통합·E2E를 실행한다. 실패·미실행과 환경 제약을 명시한다.
- 요구사항·상세 설계·테스트 체크리스트를 실제 상태에 맞게 갱신한다. 구현되지 않은 기능을 완료로 기록하지 않는다.
- 원본을 보존하고 라이선스와 배포 조건을 확인한다. 신규 코덱은 필요성과 배포 가능성 검증 없이 추가하지 않는다.
