# 테스트 및 E2E 체크리스트

상태: 전체 미실행. 체크 표시는 실제 실행과 결과 확인 후에만 변경한다. 구현 단계와 계약은 [구현 계획](implementation-plan.md), [상세 설계](detailed-design.md)를 따른다.

## 시간과 편집 모델

- [ ] `TC-001` 정수·비정수 FPS에서 프레임과 유리수 시간 변환의 시작 포함·끝 제외 경계를 검증한다.
- [ ] `TC-002` VFR PTS, 키프레임 사이 탐색, 중복·누락 PTS와 지원 불가 판정을 검증한다.
- [ ] `TC-003` A/V 시작 오프셋과 샘플 경계 반올림을 검증한다.
- [ ] `TC-004` 분할·트림·이동·충돌 거부, 연결/분리, 이력과 원본 보존을 검증한다.
- [ ] `TC-005` 빈 구간 및 클립 리플 삭제, 다른 트랙의 교차 클립 거부를 검증한다.
- [ ] `TC-006` 스키마 오류, 버전 불일치, 저장 실패, 재연결 및 복구 시 기존 파일을 보존한다.

## 미디어와 출력

- [ ] `TC-010` 실제 배포 후보 엔진에서 probe와 식별 가능한 프레임 추출을 검증한다.
- [ ] `TC-011` 연속 탐색에서 늦게 도착한 결과를 폐기하고 취소한 작업의 자원을 회수한다.
- [ ] `TC-012` 알려진 신호로 오디오 분리·게인·음소거·페이드·믹싱·클리핑 및 동기화를 검증한다.
- [ ] `TC-013` 재디코딩한 출력의 프레임 순서·경계·길이와 오디오 신호를 정량 허용 오차로 검사한다.
- [ ] `TC-014` 손상 파일, 미지원 코덱, 저장 실패, 출력 취소 및 임시 파일 정리를 검증한다.

## Extension Host E2E

- [ ] `E2E-001` 격리된 VS Code에서 프로젝트를 만들고 미디어를 가져온다.
- [ ] `E2E-002` 프레임을 탐색·추출하고 클립을 분할·이동·트림·리플 삭제한 뒤 undo/redo한다.
- [ ] `E2E-003` 원본 오디오를 분리하거나 음소거하고 배경음악을 믹싱한다.
- [ ] `E2E-004` 저장·재열기, 원본 누락·재연결과 복구를 확인한다.
- [ ] `E2E-005` 실제 엔진으로 내보내고 결과를 재디코딩해 영상·오디오를 확인하며 원본 해시가 유지되는지 확인한다.
- [ ] `E2E-006` 깨끗한 환경에 VSIX를 설치하고 포함된 코덱과 라이선스 자료를 확인한다.

## 검증 기록

실행 시 테스트 ID, 날짜, 커밋 또는 작업 트리, OS·아키텍처, VS Code 및 엔진 버전·빌드, 명령, 결과·로그, 사용한 픽스처와 허용 오차를 기록한다. 자동 테스트와 실제 장치·화면 수동 검사는 구분한다. 환경 제약으로 실행하지 못한 항목은 미완료로 남기고 사유를 기록한다.
