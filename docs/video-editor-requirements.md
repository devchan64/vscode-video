# VS Code 비디오 편집기 기능 요구사항

## 목표

VS Code에서 원본 미디어를 유지하면서 영상을 프레임 단위로 탐색하고, 자르고 이어 붙이며, 오디오를 편집한 뒤 결과물을 내보내는 비디오 편집기를 만든다. Premiere Pro, iMovie, Final Cut Pro의 기본 편집 흐름을 참고한다.

이 문서는 초기 기능 목록이다. 지원 운영체제와 미디어 형식, 성능 목표 등은 구현 전에 결정한다.

## 우선순위

- **MVP:** 미디어 가져오기부터 영상·오디오 편집, 프로젝트 저장, 오픈 라이선스 코덱을 이용한 내보내기까지 완결된 작업 흐름에 필요하다.
- **다음 단계:** MVP 안정화 이후 기본적인 표현력과 편집 편의성을 높인다.
- **고급 기능:** 별도 요구사항과 설계가 필요한 확장 기능이다.

## MVP

### 프로젝트와 미디어

- 프로젝트를 생성, 열기, 저장한다.
- 원본 미디어를 변경하지 않고 편집 정보를 별도로 저장한다.
- 영상과 오디오 파일을 가져오고 미디어 목록에 표시한다.
- 길이, 해상도, 프레임 레이트, 코덱, 오디오 채널 등 미디어 메타데이터를 조회한다.
- 원본 파일을 찾을 수 없으면 사용자에게 알리고 파일을 다시 연결한다.
- 프로젝트를 자동 저장하고 편집 작업을 실행 취소·다시 실행한다.

### 디코딩과 프레임 추출

- 지정한 시간 또는 프레임 위치의 영상을 디코딩한다.
- 디코딩한 프레임을 미리보기에 표시하고 이미지 파일로 저장한다.
- 이전·다음 프레임으로 이동하고 타임라인의 지정 위치를 탐색한다.
- 필요한 경우 앞선 키프레임부터 디코딩해 요청한 프레임을 정확하게 표시한다.
- 타임라인용 썸네일을 생성하고 캐시한다.
- 오디오를 디코딩하고 파형을 생성한다.
- 지원하지 않는 코덱이나 손상된 파일의 오류를 표시한다.

### 타임라인 편집

- 영상과 오디오를 타임라인에 추가한다.
- 클립을 이동, 삭제하고 순서를 변경한다.
- 클립의 시작점과 끝점을 조정한다(트림).
- 재생 헤드 위치에서 클립을 분할한다.
- 클립을 연속 배치해 이어 붙인다.
- 빈 공간을 삭제하고 뒤쪽 클립을 당긴다(리플 삭제).
- 타임라인을 확대·축소하고 스크롤하며 재생 헤드를 이동한다.
- 프레임 단위로 이동하고 시간 코드를 표시한다.
- 클립 경계와 재생 헤드에 맞추는 스냅을 제공한다.
- 영상과 원본 오디오를 연결해 함께 이동하거나 트림한다.

### 오디오 편집과 믹싱

- 영상에 포함된 오디오를 음소거하거나 분리한다.
- 분리한 오디오를 이동, 트림, 분할, 삭제한다.
- 배경음악과 효과음을 추가한다.
- 여러 오디오 트랙을 동시에 재생하고 믹싱한다.
- 클립별·트랙별 볼륨과 음소거를 설정한다.
- 오디오 파형을 표시한다.
- 오디오에 페이드 인·아웃을 적용한다.
- 영상과 연결된 오디오의 동기화를 유지한다.

### 화면 모드

- **미리보기 모드:** 영상을 넓게 표시하고 재생·일시정지, 탐색, 프레임 이동과 오디오 청취에 집중한다. 타임라인 편집 컨트롤은 표시하지 않는다.
- **편집 모드:** 영상 화면과 타임라인을 함께 표시하고 클립·오디오 편집을 제공한다. 편집 중에도 재생과 프레임 탐색이 가능하다.
- 두 모드를 명시적인 UI와 키보드로 전환하며, 전환 시 프로젝트와 편집 이력, 선택 및 재생 위치를 유지한다. 미리보기 모드에서는 프로젝트를 변경하는 편집 명령을 실행하지 않는다.
- 미리보기 대상은 원본 미디어와 프로젝트 타임라인 중에서 명시적으로 선택한다.

### 미리보기와 재생

- 원본 미디어와 편집된 타임라인을 각각 미리본다.
- 재생·일시정지, 시작·끝 이동, 프레임 단위 이동을 제공한다.
- 현재 시간, 전체 길이, 재생 헤드 위치를 표시한다.
- 영상 편집과 오디오 믹싱 결과를 함께 재생한다.
- 처리 속도가 부족할 때 미리보기 품질을 조절한다.
- 편집이나 탐색 중 오래된 디코딩 요청을 취소하고 최신 위치를 우선 표시한다.

### 인코딩과 내보내기

- 편집된 타임라인을 하나의 영상 파일로 렌더링한다.
- 초기 출력은 배포 가능한 오픈 라이선스 구현체를 사용하는 한 가지 형식으로 제공한다. WebM/VP9/Opus를 우선 검증하며, 최종 형식은 배포 조건과 호환성 검증 후 확정한다.
- 프로젝트 해상도와 프레임 레이트, 출력 영상 품질 또는 비트레이트를 설정한다. MVP 출력은 프로젝트 프레임 레이트를 따른다.
- 오디오 포함 여부와 기본 오디오 품질을 설정한다.
- 출력 경로 선택, 진행률 표시, 취소 및 오류 보고를 제공한다.
- 내보내기 완료 후 결과 파일을 열 수 있다.
- 출력의 시간, 화면 구성, 클립 경계와 오디오 믹싱이 타임라인과 일치한다.

### VS Code 확장 기능

- 명령 팔레트에서 프로젝트를 생성하고 연다.
- 편집기 탭에 미리보기 모드와 편집 모드를 제공한다.
- VS Code 테마와 단축키 체계에 맞는 UI를 제공한다.
- 작업 진행률과 오류 메시지를 표시한다.
- 사용자가 설치한 미디어 처리 도구의 경로와 기능을 확인하고, 누락 시 설치·설정 방법을 안내한다. 코덱의 확장 패키지 동봉은 필수가 아니다.
- 프로젝트 파일과 원본 미디어 경로를 관리한다.

## 배포와 라이선스 요구사항

디코더·인코더 후보와 배포 조건은 [코덱 라이선스 비교](codec-license-comparison.md)를 참고한다.

- 확장 기능과 함께 배포하는 모든 의존성, 실행 파일, 코덱 및 기타 자산은 계획한 배포 방식에서 재배포가 허용되는 오픈 라이선스여야 한다.
- 프로젝트의 라이선스와 배포 방식은 아직 미정이다. 구성 요소를 채택하기 전에 프로젝트 라이선스와의 호환성, 상업적 이용 가능 여부, 고지·소스 제공 등 의무와 비용을 확인하고 기록한다. GPL도 조건을 준수하면 배포할 수 있으므로 일률적으로 배제하지 않는다.
- FFmpeg는 실제 배포할 바이너리의 버전, 빌드 옵션 및 포함 라이브러리에 따라 적용 조건이 달라질 수 있다. 해당 빌드를 확인하고 라이선스 의무를 충족한다. 예를 들어 x264는 GPL 또는 별도 상용 라이선스로 제공되므로 포함 여부를 확인한다.
- H.264, AAC 등은 구현체의 소프트웨어 라이선스와 별도로 코덱 표준에 관련된 특허 및 배포 지역·용도별 조건을 검토한다. 이러한 형식의 지원은 필요성과 배포 조건을 확인한 뒤 별도로 결정한다.
- 릴리스 전에 의존성 목록과 라이선스, 출처, 적용 조건 및 필요한 고지와 소스 제공 방법을 정리하고 배포 패키지에 필요한 자료를 포함한다. 사용자가 별도로 설치하는 도구도 획득 및 사용 조건을 안내한다.

## 초기 기술 결정 사항

1. **시간 표현:** 프레임 레이트와 시간 기준을 정확하게 표현한다. 29.97fps 같은 비정수 프레임 레이트와 가변 프레임 레이트 영상의 동작을 정의한다.
2. **원본과 타임라인 위치:** 클립의 원본 시작·끝 위치와 타임라인 배치 위치를 별도로 관리한다. 분할과 트림은 원본 파일을 변경하지 않는다.
3. **프레임 정확도와 동기화:** 탐색, 분할, 추출, 내보내기에서 같은 프레임을 가리키도록 한다. 오디오는 샘플 기준으로 처리하므로 영상과의 동기화 규칙을 정의한다.
4. **지원 범위:** 첫 버전의 운영체제, 입력 코덱, 최대 해상도와 출력 형식을 정한다. 입력과 출력 지원 범위는 별도로 관리한다.
5. **미디어 처리 엔진:** FFmpeg 등의 사용 여부와 배포 방식, 플랫폼별 실행 파일 및 라이선스를 검토한다.
6. **성능과 복구:** 긴 영상에서도 UI가 멈추지 않도록 미디어 처리를 분리하고, 캐시 용량 제한과 작업 취소·실패 복구 방식을 정의한다.

## MVP 완료 기준

다음 사용자 흐름을 수행하고 결과를 검증할 수 있어야 한다.

1. 영상 두 개와 배경음악을 가져온다.
2. 프레임 단위로 탐색하고 영상을 자른다.
3. 클립 순서를 바꾸고 이어 붙인다.
4. 원본 오디오를 제거하거나 볼륨을 조절하고 배경음악을 믹싱한다.
5. 프로젝트를 저장하고 다시 연다.
6. 지원하는 형식으로 내보내고 결과의 화면과 소리가 타임라인과 일치하는지 확인한다.
